Each code snippet below has one bug in the function definition or its body. Type the corrected line in the box.

Bug 1 — Wrong parameter list

def draw_food(food_x, food_y): # missing a parameter!
Called as: draw_food(screen, food_x, food_y) — 3 arguments passed, but only 2 parameters defined.
💡 Hint: The function draws onto a surface — add the missing first parameter.

Bug 2 — print instead of return

def check_wall(hx, hy): print(hx < 0 or hx >= GRID_COLS or hy < 0 or hy >= GRID_ROWS)
The caller does: if check_wall(snake[0][0], snake[0][1]): running = False — but check_wall always returns None!
💡 Hint: To give a value back to the caller, use return, not print.

Bug 3 — Missing colon

def show_score(surface, score) # SyntaxError!
💡 Hint: Every def line must end with a : to open the function body.

def draw_snake(surface, snake):

Tier 4 Create From Scratch Write game_over_screen(surface, score, font) from scratch

Write a complete game_over_screen(surface, score, font) function. It should:

  • Clear the screen: surface.fill(BG)
  • Render "GAME OVER" centered on screen using a large font size (36)
  • Render the final score below it
  • Update the display: pygame.display.flip()
