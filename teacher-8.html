STEP 8 OF 10  ·  FACILITATOR NOTES

Save High Score

Core concepts: file I/O  ·  open()  ·  try/except  ·  f-strings  ·  leaderboard dictionary

← Step 7 Student Page Step 9 →
⏱ Suggested pace: 25–30 minutes  ·  File I/O and try/except are the two new Python concepts — let students break the program first (delete the save file) to motivate the error handling.

🎯 Learning Objectives

  • Use open() with modes "r" and "w" to read and write text files
  • Handle FileNotFoundError with try / except
  • Use f-strings to format strings with embedded values
  • Build a simple leaderboard using a dictionary

💡 The Big Idea — Annotated Code

SCORE_FILE = "high_score.txt"

# ── Load high score from file ──
try:
    with open(SCORE_FILE, "r") as f:
        high_score = int(f.read().strip())  # strip() removes newline
except FileNotFoundError:
    high_score = 0   # first time running — file doesn't exist yet
except ValueError:
    high_score = 0   # file exists but content is not an integer

# ── Save high score to file ──
def save_score(score, high_score):
    if score > high_score:
        high_score = score
        with open(SCORE_FILE, "w") as f:
            f.write(str(high_score))
    return high_score

# ── f-string formatting ──
name = "Nurul"
score = 42
print(f"Player: {name} — Score: {score:04d}")  # → "Player: Nurul — Score: 0042"
pygame.display.set_caption(f"Snake — Score: {score}  Best: {high_score}")

# ── Leaderboard (dictionary) ──
leaderboard = {}   # {"PlayerName": best_score}

def update_leaderboard(name, score):
    if name not in leaderboard or score > leaderboard[name]:
        leaderboard[name] = score

Key concept explanations

  • with open(path, mode) as f: — the with statement ensures the file is closed even if an error occurs. "r" = read, "w" = write (overwrites), "a" = append.
  • try / except — try runs code that might fail; except ExceptionType: catches a specific error type. Always catch the most specific exception you can.
  • FileNotFoundError — raised when open() is called on a file that doesn't exist. Common in file I/O — always handle it.
  • .strip() — removes leading/trailing whitespace including (newline). A file read with f.read() often ends with a newline.
  • f-strings f"..." — embed expressions directly in strings with {variable}. {score:04d} formats as a 4-digit integer with leading zeros.

🔢 Activity Answers

Tier 1 — Check Understanding

QuestionAccepted answer
What does open(file, "w") do if the file already exists? Overwrites it completely — the old content is lost.
Why use try / except FileNotFoundError? The file won't exist on the first run. Without the try/except, the program crashes immediately.
What does .strip() remove? Whitespace at the start and end of a string — including spaces, tabs, and newlines ( ).
What does the f in f"Score: {score}" do? Creates an f-string — Python replaces {score} with the variable's value.

Tier 2 — Fix the Bug

Bug: high_score = int(f.read()) without .strip() — crashes if file has a trailing newline.

Error: ValueError: invalid literal for int() with base 10: '42 '

Fix: high_score = int(f.read().strip())

Tier 3 — Extend: Save the leaderboard to a CSV file

import csv

def save_leaderboard(leaderboard, filename="leaderboard.csv"):
    with open(filename, "w", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["Name", "Score"])
        for name, score in sorted(leaderboard.items(), key=lambda x: -x[1]):
            writer.writerow([name, score])

def load_leaderboard(filename="leaderboard.csv"):
    scores = {}
    try:
        with open(filename, "r") as f:
            reader = csv.DictReader(f)
            for row in reader:
                scores[row["Name"]] = int(row["Score"])
    except FileNotFoundError:
        pass
    return scores

Reflective Journal — Suggested Strong Answers

PromptKey ideas a strong answer contains
1. What happens to data when a program ends? Variables in RAM are lost. Only data written to a file (or database) persists.
2. What is a file "mode"? The string passed to open() that specifies how to open the file: "r" = read, "w" = write, "a" = append.
3. When should you use try/except? When an operation might fail for predictable reasons — file not found, network error, invalid input. Handle specific exceptions, not bare except:.
4. What is an f-string? A string literal prefixed with f that allows Python expressions inside {} to be evaluated and embedded.
5. Explain file I/O to a classmate "Reading a file is like opening a book; writing is like printing on a page. The with statement is like using a bookmark — it keeps your place and closes the book when done."

⚠️ Mistakes Students Actually Make

What they did What they see What to say
open(file, "w") to read File is silently overwritten with nothing — old high score lost ""w" is write mode — it DESTROYS existing content. Use "r" to read."
No .strip() on f.read() ValueError — the integer string has a trailing newline "Files often end with . .strip() removes it. Always strip before converting to int."
except: (bare) Catches everything including KeyboardInterrupt and SystemExit "Always specify the exception: except FileNotFoundError:. Bare except: is a bad habit that hides real errors."
Forgot str() in f.write(score) TypeError: write() argument must be str, not int "f.write() takes a string. Convert first: f.write(str(high_score)) or use an f-string."
f"Score: " + score TypeError: can only concatenate str (not "int") to str "Inside an f-string, put the variable in braces: f"Score: {score}". Don't use + with f"..." — it defeats the purpose."

🗣️ Teaching & Facilitation Notes

Opening hook

"What happens to your high score if the power goes out?" For students who've played arcade games, this is intuitive. File I/O is how software remembers things beyond a single session.

Motivating try/except

Before explaining it, ask students to delete high_score.txt (or pretend they're running for the first time) and run the code without the try/except. They'll see the crash. Now add try/except and show it works. Failure first, solution second — the most memorable teaching sequence.

The "with" statement

Emphasise that with open(...) as f: automatically closes the file. Without it, forgetting f.close() can cause data loss or file locks. "It's like a responsible borrower — it returns the book before walking out the door."

f-strings vs % formatting

Some students may have seen "Score: %d" % score in older tutorials. f-strings are the modern, readable standard — steer students toward them.

CT connection — Persistence

💬

Ask: "What other game data might you want to persist across sessions? Player settings? Unlocked levels? Items? What file format would you use?" This opens the door to JSON and databases.
