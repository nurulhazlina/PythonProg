Tier 2 Find & Fix the Bugs 3 bugs to correct

The function definitions below have 3 bugs. Type the corrected line for each.

# Bug 1 – range() with no argument
for _ in range():          # TypeError — range() needs at least one argument
    bonus_foods.append([random.randint(0, GRID_COLS-1),
                        random.randint(0, GRID_ROWS-1), time.time()])

# Bug 2 – modifying the list during iteration
for bf in bonus_foods:
    if time.time() - bf[2] >= 8:
        bonus_foods.remove(bf)   # skips items — some foods never removed!

# Bug 3 – enumerate unpacked incorrectly
for bf in enumerate(bonus_foods):   # enumerate gives (i, bf), not just bf
    bx, by, _ = bf                  # TypeError: too many values to unpack

Bug 1

Buggy line:

for _ in range():

Your fix:

Hint: range() requires at least one argument — the stop value. To repeat 3 times, pass 3.

Bug 2

Buggy line:

bonus_foods.remove(bf)

Your fix (describe the approach):

Hint: Never remove from a list while iterating — it skips items. Build a new list that keeps only what you want.

Bug 3

Buggy line:

for bf in enumerate(bonus_foods):

Your fix:

Hint: enumerate() yields pairs — you must unpack both the index AND the item: for i, bf in enumerate(...):
